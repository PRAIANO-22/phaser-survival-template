# Phaser Survival Framework

A modular Phaser 3 framework for building Vampire Survivors-style games.

## Features

✔ Modular Architecture

✔ Weapon System

✔ Upgrade System

✔ XP & Leveling

✔ Wave System

✔ Enemy Variants

✔ Boss System

✔ Object Pooling

✔ Drone Companion

✔ HUD

✔ Game Over & Restart

---

## Built With

* Phaser 3
* JavaScript ES6
* Vite

---

## Project Structure

src/

├── combat/

### Bosses

* XP Collection
* Level Up
* Upgrade Selection
